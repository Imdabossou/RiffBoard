# Upstream reference docs

These come from [fee[dB]ack](https://github.com/got-feedback/feedBack), which RiffBoard is forked from. `feedpak-spec.md` describes the feedpak song format RiffBoard reads (RiffBoard uses the guitar and bass parts of it: arrangements, stems, lyrics, the song timeline). Upstream's own history is in its repository.

RiffBoard's own server and game are described in [../../CLAUDE.md](../../CLAUDE.md).
